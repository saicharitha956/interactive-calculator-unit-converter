 # Interactive Calculator & Unit Converter

## About the Project
A simple Python CLI application that performs basic arithmetic, unit conversions, and currency conversions.

## Features
- Addition, subtraction, multiplication, and division
- Kilometres to miles conversion
- Celsius to Fahrenheit conversion
- INR to USD and USD to INR conversion
- Input validation using `while` loops and `try-except`
- Interactive menu with an exit option

## Technologies Used
- Python 3
- VS Code

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in the terminal.
4. Run the command:

```bash
py calculator.py
```
